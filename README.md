# Emayka Store

Разработка интернет-магазина одежды Emayka.

## Стек

- **Backend:** Laravel 12, PHP 8.2+, PostgreSQL, Redis.
- **Admin:** Filament 4.
- **Storefront:** Next.js 15, React 19, TypeScript.

## Структура

- `backend/` — Laravel API и будущая админ-панель Filament.
- `frontend/` — Next.js storefront.
- `docs/` — архитектура, требования и контракты интеграций.

## Ветки

- `main` — стабильная ветка.
- `develop` — основная ветка разработки.
