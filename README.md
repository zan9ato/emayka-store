# Emayka Store

Разработка интернет-магазина одежды Emayka.

## Стек

- **Backend:** Laravel 12, PHP 8.2+, PostgreSQL, Redis.
- **Admin:** Filament 4.
- **Storefront:** Next.js 15, React 19, TypeScript.

## Структура

- `backend/` — Laravel API и будущая админ-панель Filament.
- `frontend/` — Next.js storefront.
- `docs/` — архитектура, требования и контракты интеграций.

## Ветки

- `main` — стабильная ветка.
- `develop` — основная ветка разработки.

## Дизайн

[Макет Emayka в Figma](https://www.figma.com/design/37bc6BSzo94FX08GHZtSgZ/Emayka?node-id=0-1)

Сейчас в `frontend/` собрана первая интерактивная визуальная версия: главная, каталог, карточка товара, корзина, избранное, оформление заказа, личный кабинет, информационные страницы и демо-админка (`/admin`). Корзина и избранное сохраняются локально в браузере. Каталог, заказы и административные данные демонстрационные. Платёжные, складские, доставочные и другие API не подключены. Фотографии в текущем прототипе — временные демонстрационные изображения; их нужно заменить локальными оригиналами из дизайн-архива перед публикацией. Сборка и браузерное тестирование ещё не выполнены.
