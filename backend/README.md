# Backend — Laravel + Filament

Здесь будет Laravel API и административная панель Filament.

## Основные модули

- Catalog
- Inventory
- Cart / Checkout
- Orders
- Payments
- Shipping
- Returns
- Content
- Accounts
- Notifications

## Локальный запуск

Инструкции будут дополнены после добавления Laravel skeleton и Docker Compose. Не храните реальные ключи API в репозитории; используйте локальный `.env`.
