# Требования и план реализации

## Функциональные требования

| Область | Требование | Предлагаемая реализация |
|---|---|---|
| Главная | Редактируемые баннеры, тексты, изображения, подборки и блоки | Content blocks + Filament Resource |
| Каталог | Категории, фильтры, карточки, сортировка | Catalog API + Next.js |
| Карточка товара | Галерея, описание, варианты, размеры, наличие | Product + Variant/SKU |
| Корзина | Проверка актуальной цены и доступности | Server-side cart validation |
| Оформление | Контакты, доставка, оплата, подтверждение | Checkout workflow |
| Аккаунт | Email-вход, профиль, заказы, избранное, возвраты | Laravel auth + account API |
| Склад | Остатки по SKU/цвету/размеру | Inventory adapter + reservations |
| Заказы | Создание, отмена, возврат денег | Order state machine + payment adapter |
| Доставка | Яндекс, Ozon, СДЭК, ПВЗ и курьер | Shipping provider adapters |
| Возвраты | Заявка, причина, фото, обратная отправка | Return requests + carrier integration |
| Админка | Заказы, возвраты, контент и операционные настройки | Filament |

## Этапы

### Этап 0 — фундамент
- Репозиторий, ветки и документация.
- Laravel API и Next.js приложение.
- PostgreSQL, Redis, Docker Compose для локальной разработки.
- Конфигурация окружений и базовые проверки CI.

### Этап 1 — каталог и контент
- Категории, товары, варианты/SKU, изображения.
- Контентные блоки главной и управление ими через Filament.
- Каталог, фильтры и карточка товара на frontend.

### Этап 2 — аккаунт и корзина
- Регистрация/вход по email.
- Профиль и избранное.
- Корзина и серверная перепроверка цены/остатков.
- Адреса покупателя.

### Этап 3 — заказ и склад
- Транзакционное создание заказа.
- Резервы и истечение резерва.
- Защита от конкурентной покупки последней единицы.
- Отмена заказа и аудит переходов статусов.

### Этап 4 — оплата
- Абстракция платёжного провайдера.
- Идемпотентная обработка webhook.
- Неопределённый статус платежа и сверка.
- Возврат средств.

### Этап 5 — доставка
- Общий контракт доставки.
- Расчёт вариантов/стоимости и выбор ПВЗ.
- Создание отправления и отслеживание.
- Подключение Яндекса, Ozon и СДЭК по доступным API и условиям аккаунтов.

### Этап 6 — возвраты и запуск
- Заявка из личного кабинета, причина и фото.
- Обратная логистика и email с QR/инструкцией.
- Админские процессы, тестирование, мониторинг и production deployment.

## Вопросы, которые нужно подтвердить до интеграций

1. Платёжный провайдер и сценарии оплаты (эквайринг, СБП, оплата при получении).
2. Какая именно услуга Яндекса имеется в виду: Яндекс Доставка или логистика Яндекс Маркета; нужны ли обе.
3. Ozon: логистика продавца через Ozon или другая программа/API.
4. Складской источник на старте и желаемый источник истины после интеграции.
5. Юридические тексты, политика обработки персональных данных и правила возврата.
6. Почтовый сервис и домен отправителя.

## Критерии готовности

Функция считается готовой после реализации backend-правил, интерфейса, обработки ошибок и автоматических тестов критичных сценариев. Наличие экранов без работающих серверных операций не считается завершённой функцией.
