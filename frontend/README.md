# Frontend — Next.js

Публичная витрина Emayka на Next.js App Router и TypeScript.

## Основные маршруты

- `/` — главная с динамическими контентными блоками.
- `/catalog/[slug]` — категория/каталог.
- `/product/[slug]` — карточка товара.
- `/cart` — корзина.
- `/checkout` — оформление заказа.
- `/account` — профиль, заказы, избранное и возвраты.

Данные и критичные операции получаем из Laravel API. Цены, остатки, резервы и итог заказа никогда не считаются доверенными только на клиенте.
